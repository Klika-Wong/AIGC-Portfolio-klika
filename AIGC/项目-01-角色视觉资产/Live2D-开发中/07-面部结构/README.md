# 面部透明拆层（私人工作素材 · v0.5）

这里以 `../../人物设定-1/人设图.png`中的**原图像素**生成编辑候选，不是另造的角色、可公开销售的画稿或已绑定 Cubism 模型。

## 实际生成

`output/` 包含 13 个有相同 1024×1536 画布坐标的 PNG/参考层、`01_face_neutral_recomposed.png`、`02_facial_parts_editable.ora`、对照图和 `manifest.json`。其中：

- `21_iris_left.png` / `21_iris_right.png`：两侧独立虹膜，命名按画面左右，不是人物本体左右。
- `20_eye_left_base.png` / `20_eye_right_base.png`：不完整的眼底/眼睑候选，使用局部推断修复原瞳孔区域；**并非画好的眼白与闭眼皮肤**。
- `11_brow_image_right.png`：可见眉毛；另一侧大部分被刘海遮挡，只有参考图。
- `30_mouth_neutral.png`、上下唇 REFERENCE：原始中立口部参考，不包括张口内腔、牙齿与舌头。
- `40_bangs_front_REFERENCE.png`：源图刘海候选，仍须精细沿发丝抠边和额头补绘。
- `00_face_underpaint.png`：带程序补色的脸部参考，不能宣称全部由真实原画无遮挡区域提供。

**静态面部回拼误差：平均 RGB 0.785/255**（以当时的 JSON 数据为准）。这不证明独立动画/版权。

## 如何私下查看

启动 `05-Agent接入/server.py` 后，打开本机 `/face-review`，可对比原画、切换各个源像素部件，做极小范围虹膜位移验证。不要把网页预览截图当成可对外发行的成品许可。
