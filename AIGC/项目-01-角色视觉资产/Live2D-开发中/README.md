## 现在就运行 AI 助手预览

```bash
cd "AIGC/项目-01-角色视觉资产/Live2D-开发中/05-Agent接入"
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8765
```

打开 http://127.0.0.1:8765 。没有真正模型时展示**人设原图透明版本**，不会变成其他角色。AI 接入示例见 [05-Agent接入/README.md](05-Agent接入/README.md)。

## 主要目录

- [04-资产生成/](04-资产生成/)：像素提取脚本、身份审核、Rig 参数目标、实际输出。
- [05-Agent接入/](05-Agent接入/)：显示预览、HTTP/WebSocket 接口、预留 Cubism 模型放置区。
- [00-设计/](00-设计/)：性格与内心气泡（由模型决定、通常不出现）。
- [01-交互/](01-交互/)：可选 aside 结构化输出与展示限制。
- [02-原型/](02-原型/)：早期独立气泡试验，不是最终运行入口。
- [03-验收/](03-验收/)：美术和工程验收。

## 操作建议

正式美术按 [身份锁定与质量审核](04-资产生成/身份锁定与质量审核.md) 修好素材，再在 Krita 中用 `.ora` 继续补画并转换 PSD，导入 Cubism Editor 绑定。导出后把整个模型包放在 `05-Agent接入/model/`，前端便可尝试加载真正的 Cubism 资源。

原始图、原始 prompt、旧实验图都不被自动修改。
