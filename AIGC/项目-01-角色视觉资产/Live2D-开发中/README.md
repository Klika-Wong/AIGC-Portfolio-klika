# 原创角色 Live2D 开发（在研）

> 当前版本：v0.1.0（设计与交互原型）；**尚未生成真实 Cubism Live2D 模型**。
> 角色归属：本仓库人物设定-1；AIRI 仅作学习参考，不作为本项目代码基础。

## 目标

把现有自主生成的角色发展成可在自有 AI 数字人系统中显示的精细 Live2D 形象。**身份、五官与服装以原始参考为准，不重新设计一个近似角色。** 新增由 AI 模型根据语境自主决定、偶尔出现的轻吐槽气泡（默认不显示，非隐藏推理）。

## 原始素材（不修改）

- 人物设定-1/主要形象.jpg：原始身份参考、五官风格参考（动漫风）。
- 人物设定-1/doubao_seedream_d1937b0f-6b17-48cb-b5ec-f1c02e74bb3d_1.jpg：近真人风格正/侧/背三视图，用于建模一致性检查。
- 人物设定-1/人物形象.txt：身份、服装、道具等硬约束。
- 人物设定-1/segments/：部分头发、外套、上衣、长裤和饰品图；**并非完整可绑定 PSD**。
- 人物设定-1/人设图.png、设定集.png：需要进入精细化审图与母版选择流程，未经审图不替换原始身份参考。

## 目录

- 00-设计/角色与轻吐槽气泡规范.md：人物保持、表情、人设边界、气泡规则。
- 01-交互/气泡事件协议.md：模型可选 aside 输出、后端安全校验与 Live2D 参数映射。
- 02-原型/thought-bubble-demo.html：**基于仓库原始形象图片**的离线可打开交互预览。它模拟模型返回 aside 或 null 的结果，不等同于 Live2D 模型或真实 AI 后端。
- 03-验收/ACCEPTANCE.md：分阶段目标、资产审计与验收标准。
- CHANGELOG.md：版本变动记录。

## 迭代阶段

1. v0.1：原始素材盘点、气泡设计、事件协议、可交互叠加层原型。
2. v0.2：母版精修（确定二维 / 近真人方向），补齐眼睑、虹膜、眉、口腔、下巴与遮挡区，统一光影、线条与画风。
3. v0.3：制作可编辑分层 PSD（需检查各部分无缺口、透明边缘、遮挡填补）。
4. v0.4：Live2D Cubism 网格、变形、脸部角度、物理摆动、表情与音频口型绑定。
5. v0.5：导出真实 .moc3/.model3.json，接入独立数字人前端和 Agent 事件总线。

## 不做的事

- 不把「原始图片的 CSS 晃动」冒充 Live2D 绑定。
- 不宣称能直接用现有 segments 拼装完整角色；它们多是服装与头发参考素材。
- 不把气泡称为模型真实的私人思维 / 隐藏推理；这是**可控的表演文本**。
- 不将私有原图、个人信息、记忆或 API 凭据发布到公共 CDN。
- 不在未确认版权、第三方模型授权与 Cubism 许可证前发布成品。

## 使用

本地以浏览器打开 02-原型/thought-bubble-demo.html，图片通过相对路径读取当前仓库的人设图。也可以使用静态文件服务器进行预览。原型无网络依赖。

此功能为「独立气泡显示层」；未来替换图片为真正 Live2D Canvas 时，不更改气泡事件协议即可接入。
