## 本地运行（读取仓库本地副本；注意 GitHub 现为 Public）

```bash
cd "AIGC/项目-01-角色视觉资产/Live2D-开发中/05-Agent接入"
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8765
```

- `http://127.0.0.1:8765/`：透明原图 + 可选聊天演示；
- `/review`：24 个全身分区逐层检查；
- `/face-review`：面部原图比对、可编辑层及微小眼球移动验证。

默认本地监听不等于具有账户认证；同一台机器上的程序可能访问接口。可选 DeepSeek 会发送输入文本到服务商；真实 Cubism 模型加载时当前网页会引用公共 CDN 脚本，严格离线版本须自托管并核对许可。

## 图层生成与修改原则

- **优先本地处理**：运行目录内的 Python 脚本，从原始图重建 PNG/ORA。
- 托管 Actions 生成流程已改为 **手动 workflow_dispatch**；其运行器仍读取仓库图片，不是离线环境。
- 已有 Git 历史及旧 Actions artifacts 不会因调整工作流消失；当前生成流程不再重复上传整套 PNG/ORA artifact。
- 修改正本需新版本，记录来源和补画操作，不覆盖人设原图。
