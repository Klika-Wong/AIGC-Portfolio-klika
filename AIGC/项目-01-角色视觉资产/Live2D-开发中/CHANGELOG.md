# CHANGELOG

## v0.4.0 — 2026-10-25

- 原人设图直接可视对照：原图、透明主体和面部特写。
- 增加 `/review` 精细化检查器，逐个检查 24 个 PNG 候选图层；支持缩放、Alpha 和底图叠加。
- CI 增加非生成式细节审计，确认来源颜色没漂移，统计重叠、修复头顶微小透明孔。
- 记录眼睛、口腔、头发和外套各类待补画事项。
- 角色 AI 运行界面与精修检查功能集成；仍没有 Cubism .moc3 或实际参数绑定。

## v0.3.0 — 2026-10-25

- 核对源仓库提示词及人物设定，明确脸部、发型、服装、道具、人体比例与完整鞋靴必须保真。
- 新增可重复生成的透明人设提取脚本及 GitHub Actions 自动资产流水线。
- 实际向 GitHub 提交 1 张透明人物主体、24 张 RGBA 候选分区、1 张总览图及 1 份可编辑 OpenRaster 文件；附质量审核/manifest。
- 新增 AI 数字人浏览器运行预览：本地 FastAPI + WebSocket，接收正常回复、可选 aside 和音频幅度事件。
- 接入层准备了放置后续 Cubism 导出模型和官方 Core 的目录；默认保持原图预览。
- CI 测试桥接接口，严肃模式不显示 aside；**尚未生成真正 .moc3/.model3.json**。

## v0.2.0 — 2026-10-25

- 修改气泡策略：由模型自主决定是否出现、内容不靠预设概率随机生成，默认 null。

## v0.1.0 — 2026-10-25

- 新建原创 Live2D 开发文件夹、身份约束、设计规范和轻吐槽原型。
