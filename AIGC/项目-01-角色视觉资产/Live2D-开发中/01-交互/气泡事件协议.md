# 轻吐槽气泡事件协议 v0.1

## 1. 定位

这是角色 UI 的偶发表演层（thought bubble / aside），与 AI Agent 思维链分离。默认拒绝展示用户敏感数据和模型内部推理。不得作为事实反馈的唯一渠道。

## 2. 建议事件结构

~~~json
{
  "type": "avatar.aside.request",
  "event_id": "evt_demo_01",
  "category": "new_task",
  "tone": "light_teasing",
  "context_safety": "normal",
  "utterance": "好，我来看看。",
  "suggested_text": null,
  "expression": "tease_smile",
  "ui_enabled": true,
  "timestamp_ms": 0
}
~~~

- category：new_task / curious / correction / revision / completed / praise / recovery。
- context_safety：normal / serious / sensitive / crisis（后三者一律不显示）。
- suggested_text：若非空仅可从服务端已审查白名单挑选；**不能把 LLM 原始自由文本直接展示**。
- event_id：用于去重与日志关联，不应包含个人信息。
- ui_enabled：用户显式开关；关闭时任何事件均隐藏。
- timestamp_ms：单调递增或标准时间戳；与音频时间轴解耦。

## 3. 触发算法（建议默认值，待 A/B 测试）

1. 收到新事件先检查 ui_enabled=true，且当前非认真/隐私模式。
2. 根据上下文白名单选 category，拒绝严重或敏感话题。
3. 同一时间最多一个气泡；若仍在展示，新事件不排队，以免累积。
4. 全局间隔不小于 120 秒；用户每次会话前 2 条消息原则上不触发。
5. 按事件概率采样（建议 0.10–0.25），按需调整；频率上限为每 10 分钟 2 次。
6. 抽取白名单文案，校验长度和字词，安全过滤后显示 1.8–3.2 秒。
7. 用户讲话、切换严肃场景、隐私模式或点击关闭时立即消失；禁止自动恢复之前气泡。
8. 记录匿名事件统计（事件类型、是否展示），默认不保存用户话语。

首版原型为本地演示，概率与冷却有显式预览按钮；生产版本应把频率和安全策略放在可测试的独立控制器。

## 4. 前端输出事件

~~~json
{
  "type": "avatar.aside.show",
  "text": "又有新任务了呀。",
  "expression": "tease_smile",
  "duration_ms": 2600,
  "priority": "low"
}
~~~

show -> hide 可用于 Web / Electron / Android 多端。显示文本用 textContent，不允许 HTML 注入；隐藏由前端计时器控制，场景切换可强制撤销。

## 5. Live2D 映射

后续由 Live2D Adapter 把 expression 映射到实际 .exp3.json 表情或 ParamBrowLY / ParamBrowRY / ParamEyeBallX / ParamMouthForm 等参数，具体值根据模型实测确定。

优先级：隐私/安全 > 用户主动关闭 > TTS 口型 / 眨眼 > 轻吐槽短表情。气泡是**覆盖在 Canvas 上方的独立 HTML UI**，不需要烘焙进模型贴图；这样方便改文案、翻译、适配手机端与辅助功能。

## 6. 建议 QA

- 10 分钟内事件频繁发生，气泡上限不被突破。
- 严肃场景 100% 不显示。
- 开关关闭后 100% 不显示。
- 同一 event_id 不重复显示。
- 快速切换场景时计时器清理干净，不闪旧气泡。
- 手机端无遮挡，超长内容安全截断。
- 中英文字体和语音字幕互不覆盖。
